# 게임 아이디어들

### 증강
1. 헤일메리
   - wave가 시작되면 플레이어들의 최대 체력이 1이 됩니다.
   - wave 시작 15초 동안 무작위 위치에 표적이 등장합니다.
   - 해당 표적을 파괴할 경우 현재 wave를 클리어합니다.
   - 만약 제한시간동안 표적이 파괴되지 않은 경우, 최대 체력이 원래 상태로 돌아오고 이번 wave의 적 난이도가 3배가 됩니다.
2. 드리프트
   - 슬라이딩을 하는 시간에 비례하게 드리프트 게이지가 차오릅니다.
   - 드리프트 게이지가 다 찼을 때마다 추가 점프 기회를 받습니다.
   - 추가 점프 기회는 최대 2회까지 충전 가능합니다.
3. 버블 캡틴 (원거리 전용)
   - 이제 원거리 공격 조준방식이 점이 아닌 영역으로 대체됩니다.
   - 해당 영역에 있는 적 중 가장 중앙에 위치한 적이 자동으로 타겟팅됩니다.
4. 모자가 된 고양이
   - 고양이는 모자가 되기로 했습니다.
   - 해당 플레이어는 움직을 수 없으며, 타 플레이어의 머리 위에 고정됩니다.
   - 컨트롤키를 통해 다른 플레이어 위치로 이동할 수 있습니다.
   - 자신이 가진 버프의 50% 효율만큼 올라타있는 플레이어에게 효과를 부여합니다.
5. YOU?
   - 모든 플레이어가 스파이더맨으로 보입니다.
   - 다른 플레이어의 닉네임이 보이지 않습니다.
   - 벽에 붙에서 이동할 수 있습니다.
6. 위기를 기회로
   - 강화된 적이 3명 등장합니다.
   - 마지막으로 처치한 각 플레이어에게 다음 증강 추가 선택 기회가 주어집니다.
7. 어이쿠 손이
   - 이동속도, 공격력, 방어력이 강화 횟수 * 10%만큼 증가합니다.
   - 최초 1회는 무조건 성공합니다.
   - 무작위 확률로 강화가 초기화됩니다.
8. 헤일로
   - 머리 위에 헤일로가 생깁니다.
